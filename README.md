# Simple Interest Calculator

## Description

The Simple Interest Calculator is a simple application used to calculate the interest earned or paid on a principal amount over a specific period.

## Formula

Simple Interest (SI) = (P × R × T) / 100



Where:

- P = Principal Amount
- R = Rate of Interest
- T = Time Period (in years)

## Example

- Principal Amount: ₹10,000
- Rate of Interest: 5%
- Time: 2 Years

Calculation:



SI = (10000 × 5 × 2) / 100



**Simple Interest = ₹1,000**

## Features

- Calculates simple interest easily.
- Accepts principal, rate, and time.
- Displays the calculated interest.
- Easy to understand and use.
